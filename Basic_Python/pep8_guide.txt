Indentation :- use 4 space per Indentation level.

Maximum Line length :- Limits all lines to a maximum of 79 characters.The Python standard library is conservative and requires limiting lines to 79 characters (and docstrings/comments to 72).

Blank Lines :- Surround top-level function and class definitions with two blank lines.
            Method definitions inside a class are surrounded by a single blank line.

Source File Encoding :- Code in the core Python distribution should always use UTF-8, and should not have an encoding declaration.
