Indentation :- use 4 space per Indentation level.

Maximum Line length :- Limits all lines to a maximum of 79 characters.The Python standard library is conservative and requires limiting lines to 79 characters (and docstrings/comments to 72).

Blank Lines :- Surround top-level function and class definitions with two blank lines.
            Method definitions inside a class are surrounded by a single blank line.

Source File Encoding :- Code in the core Python distribution should always use UTF-8, and should not have an encoding declaration. 

Module Level Dunder Names :- Module level “dunders” (i.e. names with two leading and two trailing underscores) such as __all__, __author__, __version__, etc. should be placed after the module docstring but before any import statements except from __future__ imports. Python mandates that future-imports must appear in the module before any other code except docstrings: 

"""This is the example module.

This module does stuff.
"""

from __future__ import barry_as_FLUFL

__all__ = ['a', 'b', 'c']
__version__ = '0.1'
__author__ = 'Cardinal Biggles'

import os
import sys
